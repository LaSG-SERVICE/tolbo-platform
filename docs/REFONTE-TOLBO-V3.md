# TOLBO V3 — Brand-first professional web experience

## Direction artistique

- Logo officiel TOLBO utilisé comme source de vérité.
- Signature de marque : « LA CONFIANCE DEVIENT UN ACTIF. »
- Bleu nuit / bleu institutionnel / orange signal.
- Photographies éditoriales liées aux données, à l'entreprise et à la décision.
- Animations légères : dashboard, score, progression, cartes flottantes.
- Accessibilité : respect de `prefers-reduced-motion`.

## Références de conception

La structure dashboard s'inspire des patterns open source Next.js/shadcn : navigation persistante, KPI, graphiques, tableaux et séparation marketing/application. Voir notamment les starters Next.js SaaS et Next.js + shadcn référencés dans la recherche UX 2026.
