# Gestion des logos

## Logo TOLBO
`public/branding/tolbo-logo.svg` est le logo de marque utilisé par l'application. Il faut le remplacer par le fichier officiel TOLBO avant production si celui fourni dans le starter n'est pas le logo officiel.

## Logo client
Le client peut envoyer un logo à l'inscription/onboarding puis depuis `Mon entreprise`. Le fichier est stocké dans `organization-logos/<organization_id>/logo.ext` et l'URL est enregistrée dans `organizations.logo_url`.

## Recommandation
Conserver deux niveaux d'identité : TOLBO reste la marque de la plateforme ; le logo du client sert à personnaliser son espace et, plus tard, les rapports autorisés.
